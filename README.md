# Booking Bot

Telegram-бот для записи клиентов к мастеру: маникюр, барбершоп, репетитор и т. п.

## Возможности

- Приветствие и главное меню с кнопками
- Раздел «Услуги и цены»
- Раздел «Контакты»
- Запись к мастеру (в разработке)

## Технологии

- Python 3.13
- aiogram 3

## Запуск

1. Клонировать репозиторий и перейти в папку проекта.
2. Создать виртуальное окружение и установить зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Создать в папке проекта файл `.env` с токеном бота от @BotFather:
   ```
   BOT_TOKEN=ваш_токен
   ```
4. Запустить бота:
   ```
   python bot.py
   ```
